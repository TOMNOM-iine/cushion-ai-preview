# クッションAI — 体験版と開発者キット

名前などを記号に置き換え、原文と見比べて確認し、回答の記号を元に戻す流れを、手元のブラウザで試せます。

**これは固定の架空文章を使う体験版です。本物のLLMによる機密検査や、ChatGPTへの送信は行いません。実在する人の名前、業務文書、APIキーを入力しないでください。**

文章の置き換えと承認・復元を体験したい人、仕組みを読んで改良したい開発者向けです。ローカルLLMとChatGPT契約を自分のアプリへ接続するための、設計・SDK・実行例・native参考ソースも含みます。[開発者向けの入口](developer/README.md)から読めます。

自分の業務文書をAIに相談する完成品ではありません。ダウンロードしてダブルクリックするMacアプリではなく、以下の準備後にブラウザで動かします。

## まず試す

Node.js 24.15以上の24系とnpmが必要です。Gitで取得するかZIPを展開して、このフォルダで実行します。

```sh
git clone https://github.com/TOMNOM-iine/cushion-ai-preview.git
cd cushion-ai-preview
npm ci --ignore-scripts
npm run verify:wasm
npm run dev
```

表示された `http://127.0.0.1:1420` を開きます。止めるときはターミナルで Ctrl+C を押します。依存パッケージの取得にはインターネットを使います。起動後のデモには、AI契約・APIキー・モデルのダウンロードは不要です。

1. 「架空のサンプルを入れる」を押す。
2. 「機密箇所を確認・変換」を押す。
3. 原文と変換文、外へ残る情報を見比べる。
4. 確認してデモ用のコピー操作を行う。内容はデモ内のメモリだけに入り、OSのクリップボードや外部AIへは渡りません。
5. 架空の回答を使い、登録済みの記号をこの画面内で復元する。

保存や実送信はこの配布物では使えません。ブラウザを閉じると相談の状態は失われます。画面上で別の接続方式を選べる場合も、実際の外部接続には進みません。

## このデモで確認できること

- 固定の架空サンプルに限る変換と比較。サンプル以外の文章は停止します。
- Rust Coreによる承認と状態管理。確認前の持ち出しを拒否します。
- 本文や目的などの変更による承認失効。古い検査結果を採用しません。
- 同じ相談で持ち出した登録済み記号だけの完全一致復元。
- 回答を文字として表示し、HTMLや外部画像を実行・取得しない扱い。

これは機密検出の精度、安全性の認証、端末全体の通信遮断を実証するデモではありません。名前を隠しても内容から人がわかる場合があります。

## ダウンロードして利用できる範囲

| 機能 | この配布物 |
| --- | --- |
| 架空データの変換・比較・承認・復元 | 試せます |
| 自分のチャット画面への組み込み | SDKと、通信しない実行例を含みます |
| 本物のローカルLLMによる検査 | 実装手順・worker・Coreの参考ソースを含みます。モデル取得とnative構築が必要です |
| ChatGPTサブスクとの自動往復 | 公式認証・送信・受信のガイドと参考ソースを含みます。native構築と本人の契約・同意が必要です |
| 外部AIのAPIキーによる通信 | native参考コードのみ。ブラウザからは通信しません |
| Macの保存庫・キーチェーン・OSコピー | 含みません |

開発中のMac本体には、ローカルモデルと、確認・承認後に変換文だけを送る別モードがあります。この公開キットで本体の全機能を利用できるわけではありません。Mac本体の一般配布、業務品質評価、署名・公証、別の端末での受入は別の作業です。

## 自分のアプリへ組み込む

1. [構成とデータの流れ](developer/ARCHITECTURE.md)を読む。
2. `npm run example` で、実Rust WASMによる検査・承認・復元と停止条件を試す。固定の架空回答を使い、外部通信はしない。
3. [ローカルLLM](developer/LOCAL_LLM.md)と[ChatGPT契約の接続](developer/CHATGPT_SUBSCRIPTION.md)を参考にnativeホストを作る。
4. [実装と受入の順序](developer/IMPLEMENTATION_ROADMAP.md)に沿って、架空データ・別端末・独立品質を検証する。

`reference/native/` は実装を読むための参考ソースです。ブラウザへ組み込まれず、そのままビルドできるnativeアプリ一式でもありません。Claudeサブスクの自動接続は含みません。

## 開発と検査

```sh
npm test
npm run build
npm run preview
```

通常の試用では生成済みWASMを使います。Coreを変更する開発者は、Rustと対応するツールを入れて再生成します。

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.104 --locked
npm run wasm:build
```

この配布物の実行対象はブラウザ・WASM向けです。参考ソースとは別に、nativeのビルド設定・不足モジュールの実装と実モデルの取得が必要です。生成物のチェックサムは破損・取り違えの検知用で、作者の署名や安全性の証明ではありません。

2026-09-30の配布候補では、別フォルダで依存取得、WASM照合、127件の試験（組み込み例6件を含む）、ビルドを実行して成功しました。架空文章によるブラウザの比較・未承認停止・復元・HTML非実行も実操作で確認しています。native参考ソースのビルド・実通信、別PCでの動作をこの配布物で検証した結果ではありません。
